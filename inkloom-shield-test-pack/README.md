# Inkloom Shield — Round 3 Test Pack

Fictional sample brand references and creatives for testing.

## Contents
- `brand-references/inkloom_brand_guidelines.md` — colors, tone, logo, accessibility and copy rules.
- `brand-references/inkloom_product_specifications.md` — approved capabilities and disallowed claims.
- `brand-references/*.png` — sample logo/reference crops.
- `marketing-creatives/*.png` — six ad/poster/social post images to upload.
- `text-test-cases/copy_audit_test_cases.md` and `.json` — test copy with expected outcomes.
- `Inkloom_Test_Pack_Overview.png` — visual overview.

## Suggested sequence
1. Add guideline and product specification text to the app's Brand Library.
2. Run TC-01 as baseline, then TC-02 to TC-08 for intentional violations.
3. Upload each creative image. Since OCR is not implemented, paste matching copy manually.
4. Register #1A237E navy and #00C896 teal in Governance Hub and compare sample creatives.
5. Test contrast pairs such as #1A237E on #FFFFFF.

## Limitations
Images are synthetic and not a real trademark. Color sampling is approximate. Expected results are evaluation guidance, not guaranteed AI outputs. Discount and event details are deliberately unapproved test values.
